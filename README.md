# SecureAuth Rollout

Enhanced the original prompt to provide clearer implementation guidance

Refined build instructions

The user wants a comprehensive web application named "MFA Rollout Plan - SecureAuth" designed as a cybersecurity capstone project to demonstrate real-world multi-factor authentication. The platform features a professional, responsive landing page with dark mode and high-end animations that lead to a secure authentication system. Users must experience a multi-step registration and login process that includes strong password validation and mandatory time-based one-time password enrollment via QR codes compatible with major authenticator apps. The system should provide a personal dashboard where users can view their security score, recent login activity, and authentication logs through visual charts and status indicators.

A centralized administrative dashboard is required to manage the user base, allowing for the toggling of security features, viewing failed login attempts, and monitoring account lockouts triggered by security policies. The application must include robust account recovery features, such as the generation of single-use backup codes and administrative reset capabilities. Users should also have a profile management area to update personal details, change passwords, and manage their authentication devices. Detailed activity logging is essential, capturing metadata like IP addresses and device information for every session.

The visual design should reflect a modern enterprise security suite, utilizing blue gradients, glassmorphism, and professional card-based layouts inspired by top-tier identity management platforms. The final product needs to include reporting tools to generate security and authentication summaries in various formats. To ensure a complete demonstration, the application should come prepopulated with sample data, including mock user accounts, administrative logs, and historical security statistics.
